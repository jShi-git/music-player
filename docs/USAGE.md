# 使用说明

## 音源与下载设置

1. 打开「设置 → 音源」，勾选需要启用的平台（默认酷我 + 酷狗 + Audius，可再勾选网易云、汽水音乐）。
2. 在「设置 → 下载」中调整「每个音乐源获取数量」与保存目录（默认 `~/Music/已下载音乐`）。

## 搜索与下载

1. 「搜索」页默认显示搜索框，结果列表上方可切换「歌曲 / 歌单」标签。
2. 在「歌曲」标签下输入歌名、歌手或关键词，回车或点击「立即搜索」，应用会在已启用音源中并发搜索。
3. 勾选歌曲后点击表头右侧的「下载选中」，或在列表底部选择下载范围后点击「下载」。
4. 点击行内播放按钮即可试听；歌曲行尾的「＋」可把当前歌曲设为下一曲、加入队列末尾或加入指定歌单。
5. 若歌曲已存在于本地曲库或下载队列，会提示跳过；同一首歌在不同歌单中只保留一份本地文件。
6. 在「歌单」标签下输入关键词，可检索网易云 / 酷我 / 酷狗的公开歌单，心形用于收藏，「打开」会跳转到「歌单 → 在线歌单」。

## 歌单

### 导入歌单

进入「歌单」页，点击顶部「导入歌单」，粘贴酷我 / 酷狗 / 网易云 / 汽水歌单链接（含 `qishui.douyin.com/s/…` 短链）或 QQ 歌单链接：

- 酷我、酷狗、网易云、汽水：直接解析公开歌单。
- QQ 音乐：先读取完整曲目，再在已启用音源中按歌名、歌手、时长逐首匹配；未匹配的曲目会跳过并提示数量。
- 导入任务转入右下角「歌单任务」面板，可收起为小窗，期间可继续浏览其它页面。

### 我的歌单 / 在线歌单

- 顶部切换「我的歌单 / 在线歌单」。我的歌单左侧为歌单导航，右侧展示歌曲详情。
- 「下载全部」可一键加入整个歌单；「选择」可勾选多首后批量下载。
- 右键歌单或点击详情页铅笔按钮可重命名，右键还可复制或删除。
- 在线歌单按平台展示热门歌单（网易云 / QQ / 酷我 / 酷狗 / 汽水），顶部搜索框可直接搜索公开歌单。
- 右侧可直接试听、解析 QQ 歌单或「导入我的歌单」；在线歌单与歌曲均可点按心形收藏。

## 音乐库

1. 「音乐库」页展示保存目录中的全部歌曲，支持本地搜索、播放全部与在 Finder 中显示。
2. 搜索框左侧可切换「本地 / 在线」：本地模式即时筛选已下载歌曲；在线模式输入关键词后在已启用音源中搜索，结果可直接试听、收藏、加入歌单或下载。
3. 左侧为歌手卡片（头像、名字与歌曲数，按歌曲数量降序排列），点击歌手后右侧只显示该歌手的歌曲，点「全部歌曲」清除筛选。
4. 右上角可在「歌曲 / 专辑」视图之间切换；点击专辑卡片会切回「歌曲」视图并定位到该专辑的歌手。

### 整理元数据

- 点击标题右侧「整理元数据 · N」进入「整理」页，扫描缺失标题 / 歌手 / 专辑 / 年份 / 封面的歌曲。
- 扫描与写入均在后台进行，期间可切换到其它页面，按钮与侧栏会实时显示进度。
- 建议置信度低于 0.6 的条目默认不勾选，请逐条核对后再写入；写入只改标签与封面，不改歌名、不重命名文件。
- 写入前可在 `/tmp` 副本上试写；未安装 ffmpeg 时会提示 `brew install ffmpeg`。

## 喜欢 / 最近

- 在搜索结果、播放页或喜欢列表中点击心形即可收藏 / 取消收藏。
- 「最近」自动记录试听过的歌曲与时间，按最近播放排序，去重并保留最近 300 首，可一键清空。
- 收藏与历史面向在线试听曲目；本地音乐库歌曲通过「音乐库」页浏览与播放，不写入播放历史。

## 电台

- 「情景」页默认以图标网格展示 84 个场景，热门情景高亮推荐。点开情景后左侧可切换情景，右侧可播放 / 暂停、换一批或点选歌曲，左上角「全部情景」回到总览。
- 「排行榜」页按平台整合为 8 张卡片，同一平台内可切换热歌 / 新歌 / 飙升等类型，每张卡片展示当前榜单前 10 首。
- 「电台」页默认载入「流行金曲」热门电台，点击即可播放；网络电台是实时直播流，不支持进度拖动与歌词。
- 情景与榜单电台会在队列快播完时自动补歌，遇到无法播放的曲目会静默跳过。
- 各页面右上角分别提供「随机情景」「随机榜单」「随机电台」。

## 播放与队列

- 底部迷你播放器显示封面、歌曲信息、波形进度与上一首 / 播放 / 下一首，右侧提供播放队列与展开播放页入口。
- 播放页展示大封面、逐行歌词与音量控制；队列按钮会在右侧展开播放列表。
- 已下载优先本地播放：本地曲库中存在同歌名 + 歌手的文件时，歌单 / 喜欢 / 最近中点播或「播放全部」会直接播放本地文件，歌单行会显示「本地」标记。
- 汽水音乐曲目只提供试听时，播放页与迷你播放器会显示「试听」标签，完整播放时显示「完整」。

## 汽水音乐会员 Cookie

在「设置 → 汽水音乐」中填入汽水音乐账号的 Cookie 并验证后，应用会尝试使用该账号的播放权益解析完整音频。受网页接口限制，部分会员曲目仍只能获取约 30 秒片段。

Cookie 可在汽水音乐 PC 客户端登录后，用 Fiddler / Charles 等抓包工具复制发往 `api.qishui.com` 的 Cookie 请求头获得。Cookie 只保存在本机，仅用于向汽水官方接口校验账号与获取播放地址。

## 跨平台自动换源

若某首歌曲在原平台因版权 / 会员 / 下架等原因无法下载，应用会按歌名、歌手与时长在酷我、酷狗、网易云中自动匹配同名歌曲（优先酷我），最多尝试 4 个候选；成功后任务会标注「已自动改用×××版本」。汽水音乐曲目下载失败时同样会换到上述平台。

## 快捷键

在菜单栏「播放」中可使用：播放 / 暂停、上一首、下一首。

## 已知限制

- 部分歌曲（尤其是网易云、酷狗）可能因版权或接口调整无法下载，或只能获取试听片段。
- 酷我无损依赖第三方解析服务，服务不可用时会自动回退 MP3。
- 表格中的「格式 / 大小」来自搜索接口返回的元数据，酷我实际下载可能为无损 FLAC，与列表显示可能存在差异。
- 汽水音乐歌单只包含公开可播放曲目；私密或已失效歌单会提示解析失败。未填写会员 Cookie 或账号非有效会员时，会员曲目只能获取试听片段；少数仅提供加密容器的曲目可能无法解析为可下载文件。
- 在线播放依赖网络与平台解析接口，接口波动或曲目下架时可能无法播放；VIP 曲目在线试听同样受片段限制。
- 电台的榜单与情景检索依赖各平台公开接口，接口调整时个别榜单可能暂时无法获取。
- QQ、Apple Music、Spotify 榜单依赖其他平台的检索结果，冷门曲目或未上架版本可能匹配失败并被跳过；Spotify 榜单页面结构若调整，对应榜单可能暂时无法获取。
- QQ 歌单导入依赖其他平台的搜索结果，冷门曲目、现场版或翻唱版本可能匹配失败或匹配到近似版本；导入后可在「来源」「时长」列核对再批量下载。
- 在线歌单来自各平台公开 Web 接口，目录内容、排序与可用性会随平台调整而变化；汽水音乐目前只有榜单可作为在线歌单浏览。
- 搜索页「歌单」标签目前只覆盖网易云、酷我、酷狗；QQ 音乐与汽水音乐暂未开放公开歌单关键词搜索。
- 整理元数据依赖网易云 / QQ 音乐的公开搜索接口与本地 ffmpeg；冷门曲目或翻唱版本可能匹配失败，建议勾选前逐条核对。
- 暂未支持 QQ 音乐、咪咕音乐的搜索与下载（原 Python 工具的这两个源接口已失效或依赖加密签名）。
- 仅供个人学习与备份合法拥有的音乐使用，请遵守各平台服务条款。
